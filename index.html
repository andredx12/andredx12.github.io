// PROJETO 01

CONTROLE PARENTAL COM IA

Machine Learning SVM + TF-IDF Python Flask Firebase
// Contexto

Sistema de controle parental orientado por ML que intercepta e classifica conteúdo web em tempo real, notificando responsáveis via app mobile conectado ao Firebase.

// Métricas
Acurácia 94.7% Recall 95.8% <200ms resposta
// Arquitetura
→ App Filho (cliente)
→ Servidor Flask (API)
→ SVM Engine (classificador)
→ Firebase (sync real-time)
→ App Pais (dashboard)
// Fluxo de Processamento
01
InterceptaçãoRequisição de conteúdo capturada no dispositivo filho via proxy local.
02
Vetorização TF-IDFTexto extraído e convertido em vetor numérico com TF-IDF para análise semântica.
03
Classificação SVMModelo SVM retorna label (seguro / impróprio) com score de confiança.
04
Ação & NotificaçãoConteúdo bloqueado ou liberado. Push notification enviado ao responsável via Firebase.
05
Dashboard ParentalHistórico completo, configurações de filtro e relatórios acessíveis em tempo real.
// PROJETO 02

BLINTEC — MINI ERP TÊXTIL

ERP Industrial C# .NET React PostgreSQL Tailwind CSS REST API Swagger
// Contexto

ERP têxtil industrial com foco em controle de produção, FIFO de rolos de tecido, comparativo de consumo planejado vs. real e sistema de auditoria por tolerância.

// Stack Técnica
→ Back-end: C# (.NET)
→ Front-end: React + Tailwind CSS
→ Banco de dados: PostgreSQL
→ REST API documentada com Swagger
// Tabela de Tolerância de Consumo
DesvioStatusAção
≤ 10%NORMALRegistro automático
10 – 20%ATENÇÃOAlerta ao supervisor
> 20%CRÍTICOBloqueio + auditoria
// Fluxo de Produção
01
Pedido de ProduçãoCliente ou planejamento gera pedido com especificações de tecido e quantidade.
02
Ordem de Produção (OP)Sistema cria OP vinculada ao pedido com consumo planejado calculado.
03
Seleção de Rolo FIFOSistema seleciona automaticamente rolos na ordem de entrada (FIFO) para garantir rastreabilidade.
04
Execução & EnfestoOperador registra início do processo; sistema monitora consumo em tempo real.
05
Registro de Consumo RealMetragem real informada e comparada com o planejado. Desvio calculado automaticamente.
06
Alertas & AuditoriaConforme a tabela de tolerância, sistema aciona alertas ou bloqueia operação para auditoria.
